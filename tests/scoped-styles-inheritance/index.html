Scoped CSS Inheritance Test

This page tests that scoped styles from parent components properly cascade to anonymous sub-components generated by if, each:, and await directives.

Test 1: Conditional Rendering (if/else)

Styles should apply to elements inside if and else blocks.

Test 2: List Rendering (each:)

Styles should apply to all items generated by each: loop.

Test 3: Async Data (await)

Styles should apply to loading, error, and data states.

Test 4: Nested Conditionals

Styles should cascade through multiple levels of conditionals.

Test 5: Mixed Directives

Styles should work when mixing if, each:, and await.
