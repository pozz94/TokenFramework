New Features Summary

  • g-caption - Table captions for accessibility and context
  • g-colgroup / g-col - Column group styling and width control
  • g-data-cell - Type-aware cells (number, currency, date, boolean)
  • g-row-header - Row header cells with rowheader role
  • Sortable headers - Click to sort columns with visual indicators
  • Enhanced spanning - Works with framework directives
  • ARIA compliance - Full accessibility support

Usage Examples


<g-table>
    <g-caption>Sales Data</g-caption>
    <g-head>
        <g-row>
            <g-header sortable>Product</g-header>
            <g-header sortable>Sales</g-header>
        </g-row>
    </g-head>
    <g-body>
        <g-row each:item=${data}>
            <g-cell>${() => item.product}</g-cell>
            <g-data-cell data-type="currency">${() => item.sales}</g-data-cell>
        </g-row>
    </g-body>
</g-table>


<g-table>
    <g-colgroup>
        <g-col width="200px"></g-col>
        <g-col width="100px"></g-col>
    </g-colgroup>

        <g-row>
