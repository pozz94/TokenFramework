Pass-through vs Read-only Test

Test 1: Signal Pass-through with `:` prefix

Child component receives the signal directly and can mutate it.

Test 2: Read-only Computed without `:` prefix

Child component receives a read-only computed value.

Test 3: Function Pass-through with `:` prefix

Child component receives the function directly and can call it.

Test 4: Function Read-only without `:` prefix

Child component receives a read-only computed that calls the function.
